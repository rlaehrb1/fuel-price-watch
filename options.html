주유소 가격 감시 설정

오피넷 무료 API는 하루 300건까지 부를 수 있습니다. 지금 설정으로는 한 번 확인할 때 0건, 하루에 약 0건을 씁니다. 이 밖에 시 일일 평균에 하루 1건, 주변 주유소 상세 정보에 처음 며칠 동안 하루 60건까지 더 쓰며, 상세 정보는 그날 남은 정기 확인에 쓸 몫을 먼저 남겨 둔 뒤에만 받습니다.

오피넷 API 키

키는 이 PC의 Chrome에만 저장됩니다.

내 주유소

찾을 때마다 호출 1건을 씁니다. 찾은 주유소는 내 주유소로 정하거나 조사 중심으로 추가할 수 있습니다.

    추가 조사 중심

    오피넷은 한 곳에서 반경 5km까지만 줍니다. 여기에 주유소를 추가하면 그 주유소 주변도 함께 조사해 한 표로 합칩니다. 하나 추가할 때마다 한 번 확인에 제품 수만큼 호출이 늘어납니다.

      비교 범위

      반경 안의 주유소는 모두 표에 나옵니다. 5km가 오피넷의 최대값입니다.

      제품

      표의 첫 번째 제품이 툴바 숫자의 기준입니다.

      알림

      백업·복원

      설정과 기록(가격 변동 90일, 하루 기록 1년, 주변 주유소 명단과 상세 정보)을 파일 하나로 저장합니다. 확장을 다시 깔거나 다른 PC로 옮길 때 불러오면 기록이 그대로 이어집니다. 확장은 평소에 이 파일을 보지 않고, 불러오기를 눌러 고를 때만 읽습니다.

      백업 파일에는 오피넷 API 키도 들어 있으니 다른 사람에게 주지 마세요. 불러오면 지금 기록은 파일 내용으로 바뀝니다.
