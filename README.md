# 주유소 가격 감시

오피넷(한국석유공사) 무료 API로 내 주유소 주변과 우리 시의 판매가격을 확인하고, 경쟁 주유소가 가격을 바꾸면 알려주는 Chrome 확장입니다.

## 보여주는 것

- 내 주유소 반경 안의 모든 주유소 가격 (최대 5km)
- 추가 조사 중심: 다른 주유소를 중심으로 반경을 하나 더 조사해 한 표로 합칩니다. 거리는 항상 내 주유소 기준입니다.
- 시·군의 평균가격과 최저가 20곳
- 다른 시·군의 면세유 최저가 20곳 (면세휘발유·면세경유·면세등유)
- 가격 변동 보기: 최근 14일의 날짜별 인상·인하 막대와, 날짜 → 확인 시각 → 주유소 순으로 묶은 변동 목록. 제품별·감시 주유소만 골라 보고, 주유소를 누르면 가격표에서 그 주유소의 기록을 펼칩니다. 새 변동이 있으면 팝업이 이 보기로 열립니다. 변동 기록은 90일 동안 남고, `CSV 저장`으로 엑셀에서 열 수 있게 내려받습니다.
- 추이 보기: 제품별로 내 가격, 감시 주유소 최저가, 시 평균을 날짜별 선 그래프와 표로 봅니다(2주·1개월·3개월). 마우스를 올리면 그날 값과 최저가 주유소가 나오고, `CSV 저장`으로 날짜별 값을 내려받습니다.
  - 내 가격과 감시 주유소 가격은 변동 기록을 거꾸로 되돌려 구하고, 그보다 오래된 날은 하루 한 칸씩 저장해 둔 기록(1년)을 씁니다.
  - 시 평균은 오피넷이 확정한 시·군 일일 평균입니다. 처음 한 번 90일 전까지 7일씩 거슬러 채웁니다.
- 경쟁사 보기
  - 누가 먼저: 제품별로 내가 가격을 바꾼 뒤 3일 안에 같은 방향으로 따라 바꾼 주유소와 걸린 시간, 그리고 여러 주유소가 함께 가격을 바꾼 흐름에서 누가 먼저 바꾸고 누가 따라가는지 셉니다. 감시 주유소만 또는 반경 전체로 볼 수 있습니다.
  - 주유소 변화: 반경 안에 새로 생긴 주유소, 이틀 넘게 반경 검색에 안 나오는 주유소(휴업·폐업 또는 가격 미등록), 상표·상호를 바꾼 주유소를 기록하고 알립니다. 면세유 주유소와 시 최저가 목록에만 나온 곳은 보지 않습니다.
- 가격표에서 주유소를 누르면 그 주유소의 변동 기록과 상세 정보(세차장·편의점·경정비·품질인증·착한주유소, 전화번호)
- 설정 화면의 백업·복원: 설정과 기록을 .json 파일 하나로 저장하고, 다시 깔거나 다른 PC로 옮길 때 불러옵니다.
- 툴바 숫자: ★ 표시한 주유소 중 최저가와 내 가격의 차이 (첫 번째 제품 기준). 새 변동이 있으면 빨간색

LPG는 다루지 않습니다.

오피넷에는 시·군의 주유소를 전부 주는 API가 없습니다. 그래서 시·군 범위는 "평균가격 + 최저가 20곳"이고, 전체 목록은 내 주유소 반경 5km까지입니다.

## 설치

1. `local-config.example.json`을 `local-config.json`으로 복사하고 API 키와 내 주유소를 적습니다. 이 파일은 저장소에 올라가지 않습니다. 건너뛰고 설치한 뒤 설정 화면에서 입력해도 됩니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위 `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 누르고 이 폴더를 고릅니다.

## 호출 수

오피넷 무료 API는 하루 300건까지입니다. 확장은 오피넷이 가격을 갱신하는 시각(1·2·9·12·16·19시)의 10분 뒤에만 가격을 받습니다.

- 한 번 확인: 일반 제품 수 × (조사 중심 수 + 1) + 면세유 제품 수 + 1건
- 조사 중심이 내 주유소 하나면 12건(하루 약 72건), 하나를 추가하면 16건(하루 약 96건)
- 시 일일 평균: 하루 1건. 처음 설치하거나 시·군을 바꾸면 지난 90일을 채우느라 한 번 13건 정도 더 씁니다.
- 주유소 상세 정보: 반경 안 주유소마다 한 번(90일마다 다시) 받습니다. 한 번 확인에 12곳, 하루 60곳까지만 받고, 그날 남은 정기 확인에 쓸 몫과 여유 10건을 먼저 남겨 둔 뒤에만 받습니다. 120곳이면 처음 이틀 동안 나눠 받고, 그 뒤로는 새 주유소나 상표가 바뀐 곳만 받습니다.
- 팝업의 `조회중지`를 누르면 자동 조회를 멈춥니다(툴바에 `중지` 표시). `조회시작`을 누르면 다시 시작하면서 갱신 시각과 관계없이 바로 한 번 확인합니다. 멈춘 동안에도 `지금 확인`은 쓸 수 있습니다.
- `지금 확인`은 5분에 한 번만 됩니다. 하루 280건을 넘으면 다음 날까지 멈춥니다.

## 개발

```bash
npm test
```

Chrome 없이 화면을 보려면 `node tools/serve.mjs`를 실행하고 `http://localhost:4391/tools/preview.html?page=popup`을 엽니다. 뒤에 `&demo=history`를 붙이면 45일치 가짜 변동 기록과 90일치 시 평균, 주유소 변화와 상세 정보로 가격 변동·추이·경쟁사 보기를 확인할 수 있습니다. 표본 자료는 `node tools/make-sample.mjs <오피넷 응답 폴더>`로 만듭니다.
