# 주유소 가격 감시

오피넷(한국석유공사) 무료 API로 내 주유소 주변과 우리 시의 판매가격을 확인하고, 경쟁 주유소가 가격을 바꾸면 알려주는 Chrome 확장입니다.

## 보여주는 것

- 내 주유소 반경 안의 모든 주유소 가격 (최대 5km)
- 추가 조사 중심: 다른 주유소를 중심으로 반경을 하나 더 조사해 한 표로 합칩니다. 거리는 항상 내 주유소 기준입니다.
- 시·군의 평균가격과 최저가 20곳
- 다른 시·군의 면세유 최저가 20곳 (면세휘발유·면세경유·면세등유)
- 가격이 바뀐 주유소와 바뀐 시각, 주유소별 변동 기록
- 툴바 숫자: ★ 표시한 주유소 중 최저가와 내 가격의 차이 (첫 번째 제품 기준). 새 변동이 있으면 빨간색

LPG는 다루지 않습니다.

오피넷에는 시·군의 주유소를 전부 주는 API가 없습니다. 그래서 시·군 범위는 "평균가격 + 최저가 20곳"이고, 전체 목록은 내 주유소 반경 5km까지입니다.

## 설치

1. `local-config.example.json`을 `local-config.json`으로 복사하고 API 키와 내 주유소를 적습니다. 이 파일은 저장소에 올라가지 않습니다. 건너뛰고 설치한 뒤 설정 화면에서 입력해도 됩니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위 `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 누르고 이 폴더를 고릅니다.

## 호출 수

오피넷 무료 API는 하루 300건까지입니다. 확장은 오피넷이 가격을 갱신하는 시각(1·2·9·12·16·19시)의 10분 뒤에만 가격을 받습니다.

- 한 번 확인: 일반 제품 수 × (조사 중심 수 + 1) + 면세유 제품 수 + 1건
- 조사 중심이 내 주유소 하나면 12건(하루 약 72건), 하나를 추가하면 16건(하루 약 96건)
- `지금 확인`은 5분에 한 번만 됩니다. 하루 280건을 넘으면 다음 날까지 멈춥니다.

## 개발

```bash
npm test
```

Chrome 없이 화면을 보려면 `node tools/serve.mjs`를 실행하고 `http://localhost:4391/tools/preview.html?page=popup`을 엽니다. 표본 자료는 `node tools/make-sample.mjs <오피넷 응답 폴더>`로 만듭니다.
